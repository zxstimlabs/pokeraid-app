# PokerAid

A poker helper app for iPhone, native in SwiftUI, scaffolded from `statemono-app`'s setup. See README.md for setup and layout.

## Conventions
- The app's name is PokerAid in anything people read: the display name (`INFOPLIST_KEY_CFBundleDisplayName`), UI text, docs. Code names stay `Pokeraid`: the target, scheme, `PokeraidKit`, types like `PokeraidApp` and the bundle ID `app.pokeraid`.
- The Xcode project is generated by XcodeGen from `project.yml` and not committed. Run `xcodegen generate` after adding or removing files; the `.xcodeproj` lists files explicitly.
- UI lives in `App/`. All non-UI logic lives in `Packages/PokeraidKit`, with tests (`swift test`).
- Swift 6 language mode, iOS 18 deployment target, iPhone only. The app target defaults to main-actor isolation with approachable concurrency; PokeraidKit doesn't, and marks CPU-heavy work `@concurrent`.
- Colors come from `Theme` (`App/Theme/Theme.swift`). Each holds both themes (`Color(light:dark:)`), so views use `Theme` colors, never `.white` or `.black`.
- Settings › Appearance sets the window's `overrideUserInterfaceStyle` (`appAppearance`), not `preferredColorScheme`: on iOS 18, going back to the system's appearance left an open sheet in the old one.
- Settings pages use `.settingsPage(_:)` for their title and Done button. `dismiss` inside a pushed page only goes back a page, so Done calls `closeSettings`.

## Working on the app
- Build after UI changes: `xcodebuild build -project Pokeraid.xcodeproj -scheme Pokeraid -destination 'platform=iOS Simulator,name=iPhone 17 Pro'`.
- To check the UI, use the simulator. `xcrun simctl io <device> screenshot` works without Screen Recording permission, and `xcrun simctl io <device> recordVideo` for motion. An iOS 18.6 runtime is installed too, with the simulator "iPhone 16 Pro iOS18", for iOS 18 bugs.
  - `simctl install` can hang on a simulator's first boot. Shut it down and boot it again.
- App icon: `App/AppIcon.icon`, an Icon Composer file (Xcode › Open Developer Tool › Icon Composer): a gradient fill and one SVG layer, currently a placeholder spade. Xcode compiles it into `Assets.car`, with flat images for older systems. Don't add an `AppIcon.appiconset`; with a `.icon` of the same name Xcode ignores it.

## Config
- IDs come from `APP_BUNDLE_ID` in project.yml (`app.pokeraid`). `DEVELOPMENT_TEAM` is Pyhash LLC's paid team (`8G6DC3A5B8`); the free personal team can't use TestFlight or App Groups.
- TestFlight: every upload needs a higher `CURRENT_PROJECT_VERSION` in project.yml.
  - Archive unsigned, then sign the archived app ad hoc: a signed archive fails because the team has no registered iPhone, which a development profile needs.
    1. `xcodebuild archive -scheme Pokeraid -destination 'generic/platform=iOS' -archivePath <path> CODE_SIGNING_ALLOWED=NO`
    2. `codesign --force --sign - <path>/Products/Applications/Pokeraid.app`. Once the app has entitlements, pass them expanded (`$(APP_BUNDLE_ID)` replaced) with `--entitlements <file> --generate-entitlement-der`, or the App Store copy won't have them.
  - Then `xcodebuild -exportArchive -allowProvisioningUpdates` with export options `method app-store-connect`, `destination upload`, `signingStyle automatic`, `teamID 8G6DC3A5B8`, `manageAppVersionAndBuildNumber false`. The export signs for the App Store and uploads with the Xcode account.
